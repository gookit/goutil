# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to semantic-ish versioning.

The release notes of every tag are generated by
[`chlog`](https://github.com/gookit/gitw) from `.github/changelog.yml` and published on the
[releases page](https://github.com/gookit/goutil/releases). This file keeps the notable,
user-visible changes, so a release only has to rename `[Unreleased]` to the new version.

## [v0.8.4] - 2026-10-24

### Fixed

- **`fsutil.UpdateContents`**: truncated the file before reading it, so the callback always got
  empty contents and the file ended up empty. It now reads the current contents first, writes from
  offset 0 and truncates to the new length; a nil `handleFn` returns an error instead of panicking.
- **`x/finder`**: the wait group, the result channel and the dir queue of a find run were fields of
  the `Finder`, so `Reset()` or a new find raced with the worker goroutines of the previous run.
  They are per-run now, and the cached elems are appended under a mutex, so no entry is lost when
  `Concurrency` is greater than 1.
- **`arrutil`**: `Filter` no longer panics on nil interface values, and `ChunkBy` bounds its
  allocation to the input length.
- **`mathutil`**: strict mode rejects floats consistently, and unsupported pointer conversions or
  nil pointer values are reported instead of being converted silently.
- **`maputil`**: values are merged into a nil inner map instead of being dropped.
- **`strutil`**: a batch of parsing and formatting fixes — zero-width runes at split boundaries,
  empty replacement keys, the zero digit in base conversion, the default padding on UTF-8 text,
  overflow-safe large substring lengths, inline comments split at the first marker, the configured
  size-range separator, byte units without a numeric value, RFC3339 fractional seconds of variable
  length, synchronised serial-number defaults, and centered strings kept within the requested width.
- **`timex`**: a zero base time falls back to `time.Now()` for the duration strings.

## [v0.8.3] - 2026-10-14

### Added

- **`cflag/capp`**: two-level sub commands. Build a group command, register the sub
  commands on it, then add the group to the app:

  ```go
  group := capp.NewCmd("session", "manage sessions")
  group.BoolVar(&verbose, "verbose", false, "verbose output;;v")

  list := capp.NewCmd("list", "list sessions")
  list.Aliases = []string{"ls"} // aliases must be set before add

  group.Add(list, capp.NewCmd("send", "send a message"))
  app.Add(group) // myapp session list
  ```

  New API: `Cmd.Add`, `Cmd.AddOrErr`, `Cmd.Sub`, `Cmd.HasSubs`, `Cmd.Parent`, `Cmd.Path`.
  A group command parses its own options **before** the sub command name, cannot declare
  positional arguments, and with no positional args it runs its own `Func` or shows the
  group help (`myapp session -h`). Nesting is recursive, but two levels are the documented
  usage; see the "两级子命令" / "Two-Level Subcommands" section of `cflag/README.md`.

### Changed

- **`strutil.SubstrCount`**: `params[0]` and `params[1]` are a rune offset and a rune
  length. An offset at or after the end of the string now gives an empty range (count `0`)
  instead of an error — the same boundary convention as `Substr()`.
- **`timex.TryToTime`**: the `"now"` keyword honors the given base time, like `"0"` and the
  duration strings do. `time.Now()` is only used when the base time is zero.

### Fixed

- **`strutil.SubstrCount`**: the default end was derived from the byte length while the
  range was sliced by rune index. On short multi-byte strings the call read past the last
  rune and returned a bogus count — `SubstrCount("你好你好", "", 1)` returned `12` instead of
  `4` — and longer byte lengths panicked with a slice-bounds error ([#271]).
- **`cflag/capp`**: a `Cmd` built from a struct literal without `CFlags` panicked while
  rendering help or parsing; the command help now also follows the app output
  (`app.SetOutput`) when the command did not set its own output.
- **`x/termenv`**: the color support level is initialized by a platform-specific `init()`,
  so the non-Windows build no longer reports `needVTP` as unused (staticcheck `U1000`).
- **`testutil`**: `RestoreTimeLocal()` left its saved location in place, so a second
  `SetTimeLocal()` in the same process panicked with "time local already set" and a test
  could not be repeated with `go test -count>1`.

[#271]: https://github.com/gookit/goutil/pull/271
