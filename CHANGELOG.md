# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to semantic-ish versioning.

The release notes of every tag are generated by
[`chlog`](https://github.com/gookit/gitw) from `.github/changelog.yml` and published on the
[releases page](https://github.com/gookit/goutil/releases). This file keeps the notable,
user-visible changes, so a release only has to rename `[Unreleased]` to the new version.

## [v0.9.0] - 2026-11-17

### Added

- **`arrutil`**: generic slice helpers that the `slices` package has and the package was
  missing: `Sort`, `SortFunc`, `SortStableFunc`, `IsSorted`, `IsSortedFunc`, `ContainsFunc`,
  `IndexFunc`, `Compact`, `CompactFunc`, `Max`, `Min`, `MaxFunc`, `MinFunc`, `Equal`,
  `EqualFunc`, `Grow`, `BinarySearch`, `BinarySearchFunc`, `DeleteFunc`, plus `Clip`, `Insert`,
  `Concat`, `DeleteRange`, `Replace`, `Repeat`, `Count` and `CountFunc`.
- **`maputil`**: `Equal` and `EqualFunc` compare two maps by their key/value pairs, `Filter`,
  `MapValues`, `Invert`, `Pick`, `Omit` and `MergeFunc` build a new map from an existing one.

### Changed

- **`arrutil`, `maputil`, `mathutil`**: the generic helpers now call the stdlib when it has them,
  behind go version build tags. On go1.21+ `SliceHas`/`IntsHas`/`Int64sHas`/`StringsHas`/`In`/
  `IndexOf`/`Reverse`/`CloneSlice` and the new slice helpers use `slices`, `Clone`/`Copy`/
  `DeleteFunc`/`Equal`/`EqualFunc` use `maps`, and `Min`/`Max` use the `min`/`max` builtins.
  `maputil.TypedKeys`/`TypedValues` use `slices.Collect(maps.Keys/Values(...))` on go1.23+.
  The hand-written versions live in the `*_legacy.go` files for the older toolchains, both
  paths run in CI (go1.19 and go1.21+). `strutil.Cut` delegates to `strings.Cut`.
- **`maputil.CloneStringMap`**: is a thin wrapper of `maputil.Clone` now, same result and the
  same nil for an empty map.

### Fixed

- **`strutil.SnakeCase`**: a known acronym stays in one word in front of a plural `s` or a
  version suffix, so `IDs` gives `ids` (was `i_ds`) and `IPv4Address` gives `ipv4_address`
  (was `i_pv4_address`). Other capitals still split, eg. `HTTPServer` -> `http_server`.
- **`strutil.ToTime`**: a `Z` at the end of a 20-char timestamp (`2024-02-29T10:00:00Z`) was a
  literal character in the layout, so the zone was dropped and the time was read in
  `time.Local`. A timestamp with fractional seconds took another path and came back as UTC,
  so the same value shifted by the local offset depending on the format. `Z` is the UTC
  designator now in both cases, which also fixes `timex.Time.UnmarshalJSON` and
  `reflects.ToTimeOrDuration` (see [#321](https://github.com/gookit/goutil/issues/321)).

## [v0.8.6] - 2026-10-29

### Fixed

- **`maputil.GetByPath`**: a typed map that the walk does not type-switch (`map[string]int`,
  `map[string]bool`, `map[MyKey]T`) was a dead end, so `GetByPath("ints.a", mp)` did not find a
  value stored as `map[string]int`. A map with a string-kind key type resolves by its key now
  (a map keyed by something else still reports not found).

## [v0.8.5] - 2026-10-29

### Added

- **`maputil.GetByPath`**: the bracket index syntax works on the get side now —
  `GetByPath("top.arr[1]", mp)` reads the slice element, and a segment can carry more than one
  index (`"top.matrix[0][1]"`). `GetByPathKeys` and `GetFromAny` support it as well, and the
  top-level key is included (`"tags[0]"`), which `SetByPath` already did. The literal key is
  always matched first, so a key that really contains brackets (eg. `"child[x]"`, `"a[0]"`)
  keeps working; the dot-index style (`"top.arr.1"`) is unchanged.

### Fixed

- **`strutil.WordWrap`**: dropped every word separator, so `WordWrap("hello world", 80)` returned
  `helloworld`. The spaces between words are kept and count toward the line width now; a separator
  becomes a newline when the next word does not fit, and a word longer than the width is still kept
  whole. Note: because the separators count now, a line can wrap one position earlier than before.
- **`jsonutil.StripComments`**: removed a `/* ... */` that sat inside a JSON string value, so
  `{"header":"/* generated */"}` lost its value. The block-comment pass matches string literals
  and line comments too and only drops the real block comments, so an escaped quote or backslash,
  a URL and a marker inside a line comment all survive.
- **`maputil.SetByPath`**: a negative slice index panicked with `reflect: slice index out of
  range`, both for an index key (`"list.-1"`) and for the bracket syntax (`"list[-1]"`). The index
  is parsed and validated now, so an invalid index returns an error and the data is left as it was;
  `MakeByKeys` keeps a negative index as a literal key instead of panicking. The get side was
  fixed in [#294].
- **`maputil.SetByPath`**: the bracket syntax works on the top key now — `SetByPath(&mp, "list[1]",
  "b")` updates (or grows, or creates) the `list` slice. It was written as a literal `"list[1]"`
  key before; a deep path like `"list[0].name"` works as well.
- **`maputil.SetByPath`**: a value that does not match the slice elem type panicked with
  `reflect.Set: value of type ... is not assignable to type ...`; it returns an error now and the
  data is left as it was. A nil value is accepted by a nil-able elem type (`any`, pointer, map...).

## [v0.8.4] - 2026-10-24

### Fixed

- **`fsutil.UpdateContents`**: truncated the file before reading it, so the callback always got
  empty contents and the file ended up empty. It now reads the current contents first, writes from
  offset 0 and truncates to the new length; a nil `handleFn` returns an error instead of panicking.
- **`x/finder`**: the wait group, the result channel and the dir queue of a find run were fields of
  the `Finder`, so `Reset()` or a new find raced with the worker goroutines of the previous run.
  They are per-run now, and the cached elems are appended under a mutex, so no entry is lost when
  `Concurrency` is greater than 1.
- **`arrutil`**: `Filter` no longer panics on nil interface values, and `ChunkBy` bounds its
  allocation to the input length.
- **`mathutil`**: strict mode rejects floats consistently, and unsupported pointer conversions or
  nil pointer values are reported instead of being converted silently.
- **`maputil`**: values are merged into a nil inner map instead of being dropped.
- **`strutil`**: a batch of parsing and formatting fixes — zero-width runes at split boundaries,
  empty replacement keys, the zero digit in base conversion, the default padding on UTF-8 text,
  overflow-safe large substring lengths, inline comments split at the first marker, the configured
  size-range separator, byte units without a numeric value, RFC3339 fractional seconds of variable
  length, synchronised serial-number defaults, and centered strings kept within the requested width.
- **`timex`**: a zero base time falls back to `time.Now()` for the duration strings.

## [v0.8.3] - 2026-10-14

### Added

- **`cflag/capp`**: two-level sub commands. Build a group command, register the sub
  commands on it, then add the group to the app:

  ```go
  group := capp.NewCmd("session", "manage sessions")
  group.BoolVar(&verbose, "verbose", false, "verbose output;;v")

  list := capp.NewCmd("list", "list sessions")
  list.Aliases = []string{"ls"} // aliases must be set before add

  group.Add(list, capp.NewCmd("send", "send a message"))
  app.Add(group) // myapp session list
  ```

  New API: `Cmd.Add`, `Cmd.AddOrErr`, `Cmd.Sub`, `Cmd.HasSubs`, `Cmd.Parent`, `Cmd.Path`.
  A group command parses its own options **before** the sub command name, cannot declare
  positional arguments, and with no positional args it runs its own `Func` or shows the
  group help (`myapp session -h`). Nesting is recursive, but two levels are the documented
  usage; see the "两级子命令" / "Two-Level Subcommands" section of `cflag/README.md`.

### Changed

- **`strutil.SubstrCount`**: `params[0]` and `params[1]` are a rune offset and a rune
  length. An offset at or after the end of the string now gives an empty range (count `0`)
  instead of an error — the same boundary convention as `Substr()`.
- **`timex.TryToTime`**: the `"now"` keyword honors the given base time, like `"0"` and the
  duration strings do. `time.Now()` is only used when the base time is zero.

### Fixed

- **`strutil.SubstrCount`**: the default end was derived from the byte length while the
  range was sliced by rune index. On short multi-byte strings the call read past the last
  rune and returned a bogus count — `SubstrCount("你好你好", "", 1)` returned `12` instead of
  `4` — and longer byte lengths panicked with a slice-bounds error ([#271]).
- **`cflag/capp`**: a `Cmd` built from a struct literal without `CFlags` panicked while
  rendering help or parsing; the command help now also follows the app output
  (`app.SetOutput`) when the command did not set its own output.
- **`x/termenv`**: the color support level is initialized by a platform-specific `init()`,
  so the non-Windows build no longer reports `needVTP` as unused (staticcheck `U1000`).
- **`testutil`**: `RestoreTimeLocal()` left its saved location in place, so a second
  `SetTimeLocal()` in the same process panicked with "time local already set" and a test
  could not be repeated with `go test -count>1`.
